# Full Screen Mode in Chrome on macOS

https://apple.stackexchange.com/questions/446692/how-to-full-screen-chrome-tab-on-a-mac

With the Chrome Window in full screen mode (green button, View > Enter Fullscreen, or FnF), the keyboard shortcut ⌘ Command⇧ ShiftF (View > "Always show toolbar in full screen mode") will toggle showing the tab/url/bookmarks bar while in full screen mode.
