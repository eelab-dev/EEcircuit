# Add Component Popover Keyboard Navigation

This document explains how to use the keyboard to navigate the "Add Component" popover.

## Opening the Popover

- Click the "Add Component" button (the plus icon) to open the popover.

## Searching for Components

- When the popover opens, the search bar is automatically focused.
- Start typing to filter the list of components.

## Navigating Between Search and Component List

- **`Tab`**: Toggles focus between the search bar and the component list.
- **`ArrowDown`**: From the search bar, moves focus to the first component in the list.

## Navigating the Component List

- **`ArrowUp`**: Moves focus to the component in the row above. If you are in the first row, it moves focus to the search bar.
- **`ArrowDown`**: Moves focus to the component in the row below.
- **`ArrowLeft`**: Moves focus to the component to the left in the same row.
- **`ArrowRight`**: Moves focus to the component to the right in the same row.

## Selecting a Component

- **`Enter`**: Adds the currently focused component to the schematic.

## Closing the Popover

- **`Escape`**: Closes the popover.
- Clicking outside the popover also closes it.
